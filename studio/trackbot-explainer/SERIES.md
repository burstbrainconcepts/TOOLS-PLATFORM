# Series mode and ad mode

Batch-produce consistent short videos on this machine: no paid APIs, no cloud. Every output is a **draft**; a person reviews before anything is posted.

## Series mode (many episodes, the same characters)

```
series/<name>/bible.json          characters (look + voice), palette, brand, CTA, lint rules
series/<name>/episodes/*.json     one file per episode: a list of scenes
node scripts/series/batch.mjs series/<name> [--only text] [--lint-only]
```

The **bible** is the single source of truth: change a character's colours or voice there and every episode follows.
Each scene picks a **template** (`hook`, `talk`, `board`, `flow`, `stat`, `product`, `outro`), who is on screen (`who`), who speaks (`speaker`, which selects that character's own voice), the spoken `text`, and template fields (`title`, `bullets`, `icons` + `labels`, `stat`, `setting`, `emotion`).

`batch.mjs` runs lint -> voices -> render -> QA -> contact sheet -> `out/batch/<id>/report.md`.
**Lint** (`scripts/series/lib.mjs`, 10 tests: `node --test scripts/series/lib.test.mjs`) rejects unknown characters/templates/icons, missing fields and banned phrases, and warns about a missing hook or CTA, long lines, repeated templates, low variety and off-target length.

`series/demo/` is a working example. **Mel is provisional**: rename or restyle in `bible.json` once the real cast is decided.

## Ad mode (product image + brief -> UGC-style ad)

```
ads/<name>/brief.json     name, tagline, pain, audience, benefits[], price, offer, cta, presenter, sidekick
ads/<name>/product.jpg    any product photo (plain background works best)
node scripts/ads/make-ad.mjs ads/<name> [--variants problem,pov,meet] [--lint-only]
```

1. `analyze.py` (OpenCV, no network) cuts the product out of its background and picks the ad colours from it. If the cutout looks unreliable it falls back to the original image.
2. `write-script.mjs` writes one ad per **hook variant** (same body, different opening) for A/B testing.
3. The same lint/voice/render/QA/report pipeline runs.

Honesty rules, enforced by lint for ads: every sentence comes from the brief, numbers must appear in the brief, superlatives ("best", "fastest", "guaranteed"...) are rejected unless listed in `brief.claimsAllowed`, and no invented testimonials. Always check the claims against reality before posting.
`ads/demo-bottle` uses a fictional product (generated by `scripts/ads/make-demo-product.py`).

## What this is not

It is a 2D vector cast with templates: consistent and cheap, not photoreal people like Arcads. Photoreal talking humans need a GPU video model or a paid service.

## Requirements

Node deps as for the rest of the studio, Piper voices in `/home/user/voices` (`VOICES_DIR`), `CHROME_PATH` for Remotion, and a Python with `opencv-python-headless` + `Pillow` for ad mode (`ANALYZE_PY`, default `/home/user/cpu-test/venv/bin/python`).

## 3D mode (set `"style": "3d"` in a bible; see `series/demo3d/`)

The cast is rendered as real 3D people (three.js, lit scene, soft shadows, blurred bokeh backdrop, reflective floor); the same
templates draw titles, cards and captions on top. Each character picks a body with `"body": "m"` or `"f"`.

- The bodies come from **MPFB** (MakeHuman plugin for Blender: code GPL-3, bundled assets CC0): detailed body and face, 53-bone rig
  with fingers, facial morph targets (blink, brows, mouth open, smile, frown). `models/setup_mpfb.sh` fetches and patches it for
  Blender 4.0; `models/build_human_mpfb.py` builds `public/models/human_m.glb` / `human_f.glb` (clothes are cut from the body surface,
  eyes, brows, hair styles, glasses and shoes are added). The built GLBs are committed, so Blender is only needed to rebuild them.
- Acting is driven by numbers (the same values as the 2D cast): nods and hand gestures on speech onsets, blinking, lip-sync from the
  voice loudness, the listener turns toward the speaker, breathing and weight shifts.
- Rendering is slow on CPU: about 4 s per 1080p frame, so a 30 s episode takes roughly 1.5 hours. Use `"quality3d": 0.75` to trade size for speed.
- Limits: skin is a flat colour (no texture), clothes are simple shells (no wrinkles, no kit details), hair is basic shapes.
